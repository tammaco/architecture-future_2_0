# Разделите систему на домены с использованием подхода Domain-Driven Design (DDD). Определите bounded contexts для каждого домена

Система разделена на домены, [схема](https://github.com/tammaco/architecture-future_2_0/Task4Advanced/Будущее 2.0_bounded-contexts.drawio)

## Описание доменов

**Domain: Patient Management**

1. Microservice: Patient Registration

- Регистрация новых пациентов

- Обновление персональных данных

- Деактивация/архивация профиля пациента

2. Microservice: Patient Profile

- Хранение и предоставление профиля пациента

- История изменений профиля

- Настройки предпочтений (тема, уведомления)

3. Microservice: Insurance

- Проверка действительности страхового полиса в реальном времени

- Интеграция с внешними страховыми системами


**Domain: Clinical Management**

1. Microservice: Appointment Scheduling

- Запись пациентов на приём к врачу

- Управление расписанием врачей

- Отмена/перенос записей с уведомлением пациента

- Интеграция с календарями врачей

2. Microservice: Medical Records

- Создание и ведение электронной медицинской карты

- Добавление диагнозов, жалоб, анамнеза

- Версионирование записей 

3. Microservice: Recipe Management

- Выписка рецептов

- Проверка взаимодействия лекарств и аллергий

- Интеграция с аптеками и фармацевтическими системами

4. Microservice: Clinical Notes

- Заметки врача к карте пациента

- Тегирование по специальностям и темам

**Domain: AI Diagnostics**

1. Microservice: AI Request Gateway

- Приём запросов на ИИ-анализ медицинских данных

- Очередь запросов с приоритизацией

- Отслеживание статуса выполнения запроса

2. Microservice: AI Model Execution

- Запуск обученных ИИ-моделей на медицинских данных

- Масштабирование вычислительных ресурсов под нагрузку

- Логирование версий моделей и времени выполнения

3. Microservice: AI Results Storage

- Хранение результатов ИИ-анализа с привязкой к пациенту

- Предоставление результатов врачам в удобном формате

- Аудит доступа к результатам

4. Microservice: AI Feedback

- Сбор обратной связи от врачей по качеству предсказаний

- Донастройка моделей на основе реальных клинических исходов

- Формирование отчётов о точности алгоритмов

**Domain: FinTech Operations**

1. Microservice: Account Management

- Открытие/закрытие финансовых счетов пациентов

- Привязка банковских карт и счетов к профилю

- Овердрафт и кредитные линии

2. Microservice: Credit Management

- Оформление заявок на кредиты и рассрочки

- Скоринг и проверка кредитной истории

- Подписание электронных кредитных договоров

3. Microservice: Payment Processing

- Проведение платежей за медицинские услуги

- Интеграция с внешними платёжными шлюзами

- Поддержка подписок и регулярных списаний

4. Microservice: Transaction History

- Полная история всех финансовых операций

- Формирование выписок для пациентов и регуляторов

- Поиск и фильтрация транзакций по датам/суммам

- Подготовка данных для налоговой отчётности

**Domain: Billing**

1. Microservice: Invoice Management

- Автоматическое формирование счетов за услуги

- Генерация счетов для страховых компаний

2. Microservice: Settlement Management

- Взаиморасчёты с клиниками и медицинскими центрами

- Закрытие финансовых периодов

**Domain: Inventory & Logistics**

1. Microservice: Stock Management

- Учёт лекарств и расходных материалов по клиникам

- Резервирование препаратов под назначения

- Инвентаризация и списание

2. Microservice: Supply Ordering

- Формирование заказов на поставку лекарств и оборудования

- Интеграция с поставщиками

- Отслеживание статуса поставок

3. Microservice: Warehouse Management

- Приёмка товаров и размещение на складе

- Сборка заказов для клиник

4. Microservice: Equipment Management

- Учёт медицинского оборудования

- Плановое ТО и ремонты

- Списание и утилизация устаревшего оборудования

**Domain: Partner Management**

1. Microservice: API Gateway

- Единая точка входа для внешних API-запросов

- Аутентификация и авторизация партнёров

- Лимитирование запросов и мониторинг

- Документация API

2. Microservice: Partner Management

- Регистрация партнёров на портале

- Проверка документов и лицензий

- Подписание электронных договоров

- Управление доступами

3. Microservice: Pharma Integration

- Интеграция с фармацевтическими компаниями

- Автоматический заказ при выписке рецептов

- Обмен данными о потребностях клиник

4. Microservice: Device Integration

- Интеграция с производителями медоборудования

- Получение данных с устройств

**Domain: Notifications**

1. Microservice: Notification Delivery

- Отправка уведомлений по email, SMS, push

- Интеграция с внешними шлюзами

- Управление шаблонами сообщений

2. Microservice: Message History

- Хранение всех отправленных уведомлений

- Поиск и фильтрация по пациентам и типам

- Экспорт для регуляторных запросов

3. Microservice: Alert Management

- Критические уведомления для врачей и администраторов

- Интеграция с системами мониторинга

**Domain: Analytics & Reporting**

1. Microservice: Operational Analytics

- Дашборды для руководства клиник

- Отчёты по эффективности работы врачей

- Прогнозирование потока пациентов

2. Microservice: Clinical Analytics

- Анализ эффективности лечения

- Отчёты по диагнозам

- Статистика по применению лекарств

- Сравнительный анализ результатов по клиникам

3. Microservice: Financial Analytics

- Отчёты по прибыли

- Анализ финансовых потоков между клиниками и партнёрами

- Прогнозирование финансовых показателей

- Подготовка отчётности 

4. Microservice: Data Lake Connector

- Выгрузка агрегированных данных в Data Lake

- Интеграция с внешними BI-инструментами

- Подготовка данных для машинного обучения

- Соблюдение политик хранения и архивации

**Domain: IAM**

1. Microservice: User Authentication

- Аутентификация врачей, операторов, пациентов

- MFA (двухфакторная аутентификация)

- SSO (Single Sign-On) для внутренних корпоративных систем

- Управление сессиями и токенами

2. Microservice: Role Management

- Гибкая система ролей

- Разграничение по клиникам и подразделениям

- Аудит изменений прав доступа

3. Microservice: Access Control

- Проверка прав доступа при каждом API-запросе

- Политики доступа на основе атрибутов и ролей

- Ограничения на уровне строк данных

- Интеграция с сервисами медицинских данных

**Domain: Audit**

1. Microservice: Audit Trail

- Логирование всех действий пользователей с данными

- Хранение логов с неизменяемостью

- Поиск и фильтрация по инцидентам

2. Microservice: Incident Management

- Регистрация инцидентов безопасности

- Уведомление ответственных лиц

3. AIRequest 
События:

- AIRequestSubmitted

- AIRequestCompleted

- AIRequestFailed

4. Credit

- CreditCreated

- CreditApproved

- CreditRejected

- PaymentMade
